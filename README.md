# APM1205 Formative Assessment 2
## Linear Models: Simple Linear Least-Squares Regression

### Overview

The assessment focuses on using simple linear least-squares regression to investigate the relationship between TV advertising expenditure and Sales using the Advertising dataset.

### Research Question

Can TV advertising expenditure be used to predict Sales?

### Variables

- **Predictor (X):** TV advertising expenditure
- **Response (Y):** Sales

### Regression Model

The fitted regression equation is:

**Saleŝ = 7.032594 + 0.047537(TV)**

### Main Results

- **Correlation (r):** 0.782224
- **R²:** 0.611875 (61.19%)
- **Residual Standard Error:** 3.259
- **TSS:** 5417.14875
- **RSS:** 2102.53058
- **RegSS:** 3314.61817

### Files

- `APM1205_FA2_Daileg_KristineArllaine_Linear_Models.Rmd` – R Markdown source file

- `Advertising.csv` – dataset used for the analysis

### Conclusion

The analysis indicates a positive and fairly strong linear relationship between TV advertising expenditure and Sales. Approximately 61.19% of the variation in Sales is explained by TV advertising expenditure.
